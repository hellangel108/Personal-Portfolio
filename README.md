# Personal Portfolio Website

A modern, animated personal portfolio website for a Senior Engineering Leader — built with React, TypeScript, Vite, and Tailwind CSS.

## Sections

- **Hero** — introduction with animated background gradient
- **About** — personal journey and core values
- **Skills** — technical expertise across languages, cloud, data, architecture, and leadership
- **Experience** — career timeline
- **Projects** — featured work and case studies
- **Impact** — key metrics and achievements
- **Contact** — get in touch

## Tech Stack

| Category | Technologies |
|---|---|
| Framework | React 18, TypeScript |
| Build tool | Vite 6 |
| Styling | Tailwind CSS v4 |
| UI Components | shadcn/ui (Radix UI), Material UI |
| Animation | Framer Motion (motion/react) |
| Icons | Lucide React |
| Routing | React Router v7 |
| Package manager | pnpm |

## Getting Started

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build
```

Dev server runs at `http://localhost:5173`
